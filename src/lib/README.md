## Purpose

The logic behind the tools: run records and their lifecycle (runs, lifecycle, prepare),
manifest and request resolution into a plan (manifest, resolve, languages, models), prompt
composition (compose, task-block, render, frontmatter), findings parsing and review posting
(findings, post-review), GitHub polling (discover), the gh CLI wrapper (gh), and deployment
init, update and Claude Code update checks (deployment). Shared types are in types.ts.
